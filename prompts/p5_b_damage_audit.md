# P5-B 损伤核验

判断这张照片的集装箱部件上是否有明显损伤。

=== 箱内拍摄常见损伤 ===
- 凹痕、裂缝、变形、弯曲
- 白色胶带、银色修补片、焊接点
- inspector黄色蜡笔编号、白色圆圈标记
- 孔洞、断裂、磨损

=== 箱外拍摄常见损伤（关键）===
- **侧板凹痕/变形**：波纹板表面不平整，有局部凹陷或凸起
- **大面积锈迹**：锈迹呈条状/块状分布，不是均匀的表面氧化
- **旧修补痕迹**：补丁、焊接痕迹、漆面差异
- **刮擦/碰撞痕迹**：表面有明显的外力撞击痕迹

=== 无损伤的特征（关键区分） ===
- 部件表面平整，波纹均匀
- 仅是均匀分布的轻微氧化/均匀锈迹（旧箱子正常老化）
- 无任何变形、凹痕、裂缝、修补痕迹
- ⚠️ **仅有锈迹但没有变形/凹痕/裂缝 → 旧箱子正常老化，不是修箱损伤 → has_damage=false**
- ⚠️ **铭牌/标识区域（CSC安全牌照、高度标识、IC标识）的轻微锈迹 → 正常老化，不是修箱损伤 → has_damage=false**

=== 修箱损伤 vs 正常老化 区分（核心判断） ===
| 修箱损伤（has_damage=true） | 正常老化（has_damage=false） |
|---|---|
| 锈迹+变形/凹痕/裂缝 | 仅有均匀锈迹，表面平整 |
| 块状/条状锈迹+漆面脱落 | 均匀氧化，无漆面脱落 |
| 旧修补痕迹/焊接点 | 无修补痕迹 |
| 明显外力撞击痕迹 | 无撞击痕迹 |
| inspector标记 | 无inspector标记 |
| 部件主体区域的损伤 | 铭牌/标识区域的轻微锈迹 |

⚠️ 重要：
- inspector标记（黄色蜡笔编号、白色圆圈）**属于损伤标记**→ has_damage=true
- 箱外侧板的**明显凹痕/变形/大面积锈迹**也是有效损伤→ has_damage=true
- **仅有均匀锈迹+表面平整 → 旧箱子正常老化 → has_damage=false**
- **铭牌/标识区域的锈迹（无变形/凹痕）→ 正常老化 → has_damage=false**
- 判断时看**部件主体区域**（波纹板本身），不是铭牌/标识区域
